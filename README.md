# Disk Analyzer

Analyzes disk usages over time.

![User interface for the application in light mode](screenshot.png)

## Getting Started

1. Install dependencies
   ```
   npm i
   ```
2. Run development build
   ```
   npm run tauri dev
   ```
3. Build for production
   ```
   npm run tauri build
   ```
4. Test rust
   ```
   cargo test
   ```
5. Format rust
   ```
   cargo fmt
   ```
